# 🌐 AI Resume & Cover Letter Tailor

A clean, lightweight client-side web utility designed to help job seekers instantly generate tailored, US-style cover letters based on specific job descriptions and their personal experience.

## 🚀 Features
- **Client-Side Execution:** Runs 100% in the browser with zero backend setup or bloat.
- **Instant Customization:** Matches job requirements with personal skills to draft professional cover letters in seconds.
- **Modern UI/UX:** Built with a sleek, dark-mode SaaS interface tailored for modern developers and professionals.
- **100% Open Source:** Simple HTML/JS architecture that is easy to customize and extend.

## 🛠️ Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/YOUR_USERNAME/ai-resume-tailor.git](https://github.com/YOUR_USERNAME/ai-resume-tailor.git)
   cd ai-resume-tailor
Launch the app:
Open the index.html file directly in any modern web browser (Chrome, Firefox, Safari, Edge).

Paste the target job description and your skills summary, then click generate!
